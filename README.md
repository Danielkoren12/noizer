# אתר NOIZER

גרסה ראשונה של עמוד עברי, מהיר וסטטי. אין תלות בחבילות, בבנייה, במפתחות API או במסד נתונים.

## פתיחה ועדכון ללא טרמינל

לתצוגה בתוך הצ׳אט או כקובץ בודד, פתחו את [preview.html](preview.html). העיצוב, הפונטים והאנימציה כלולים בו, ולכן הוא אינו תלוי בטעינת קבצים נוספים. הוא נוצר ממקורות האתר באמצעות `scripts/build_preview.py`; יש לעדכן אותו כשמשנים את המקורות.

לפתיחת הפרויקט המלא, פתחו את [index.html](index.html) בדפדפן בלחיצה כפולה כשהוא נמצא לצד יתר קבצי הפרויקט. לפתיחה בסביבת פיתוח אפשר גם לבחור בתוסף Live Server בעורך וללחוץ **Go Live**. אין צורך להתקין חבילות עבור האתר.

- **טקסט ומבנה:** `index.html`.
- **עיצוב, צבעים ומובייל:** `styles.css`. הצבע הראשי מוגדר בראש הקובץ ב־`--blue`.
- **אנימציה, מתג הבאנרים וקשר:** `app.js`.
- **נכסים ורישיונות פונטים:** `assets/`.
- **עובדות העסק והחלטות העיצוב:** `PRODUCT.md` ו־`DESIGN.md`.
- **סקילי העיצוב:** `.agents/skills/`. יש לקרוא את ההנחיות לפני שימוש; אין אישור להרצת סקריפטים חיצוניים.

## השלמת הנכסים

שני סרטוני היוצרים שנמסרו שולבו במסגרות 9:16 הקיימות. הם נטענים ומופעלים בלחיצה בלבד, עם תמונות פתיחה מתוך הסרטונים עצמם; כפתורי הפעלה/עצירה וקול נגישים נמצאים מעל התוכן ואינם מכסים את הבאנר. כפתור ״הסתירו את הבאנר״ שולט בבאנרים בלבד. שני הבאנרים המקוריים שסופקו שולבו באותו רוחב, גובה ומיקום של הבאנרים הקודמים. במקום משבצת דמות הספריי נוסף, לפי הבקשה המעודכנת, ילד מקורי בשחור שמצויר כ־SVG בקוד. הדמות הקטנה מוצגת מהגב, הולכת עם חשיפת הטקסט וחוזרת לתחילת השורה הבאה. הכתיבה נמשכת כ־6 שניות, עם ציר זמן משותף לדמות ולאותיות; אין תמונת AI או תלות בקובץ תמונה חיצוני. האנימציה מופעלת פעם אחת בביקור, ללא סאונד וללא כפתור הפעלה חוזרת; בהעדפת פחות תנועה הדמות נשארת סטטית.

קובצי הסרטונים ותמונות הפתיחה נמצאים תחת `assets/examples/`. הבאנרים `velqor-banner.png` ו־`roamiq-banner.png` הם קובצי המשתמש המקוריים ללא שינוי. `.real-banner` שומר על מידות ומיקום `.mock-banner`: גובה 60 פיקסלים ומרחק 28 פיקסלים מהתחתית בדסקטופ; 47 ו־22 פיקסלים במובייל. הסרטונים אינם מוצגים כהוכחה ללקוח משלם או לתוצאות קמפיין.

כאשר יתקבל קובץ הלוגו המקורי, יש להחליף את `.wordmark` בראש העמוד ובתחתית בתמונת הלוגו עם alt בשם NOIZER ומידות מוגדרות. שם המותג הנוכחי בטקסט הוא זמני. יש לאמת את הכחול מול הנכס המקורי.

## קשר

שני הכפתורים פותחים את אפליקציית הדוא״ל ל־`daniel@noizer.co.il`, עם נושא נפרד ותבנית קצרה. הפעולה תלויה בהגדרת אפליקציית דוא״ל במכשיר. הכתובת מוצגת גם כטקסט, עם אפשרות העתקה כשהדפדפן מאפשר זאת. המספר `055-666-7720` פותח שיחת WhatsApp בחלון חדש. ההודעה נשלחת רק אם המבקר בוחר לשלוח אותה ב־WhatsApp. האתר אינו שולח דוא״ל בעצמו, אינו שומר פרטים ואינו כולל טופס עם חיווי הצלחה מדומה.

קישורים לעמודי Instagram, LinkedIn ו־TikTok הרשמיים מופיעים בתחתית האתר, וכתובותיהם נכללות ב־`sameAs` בנתוני העסק המובנים.

## פרסום וסריקה

### פרסום ב־Netlify בלי פקודות

הפרויקט כולל תיקיית אתר מוכנה `public/` ו־`netlify.toml` שמגדיר את פרסומה ישירות, ללא פקודת בנייה ב־Netlify. אין להשתמש בתיקיית הפרויקט כולה כתיקיית פרסום.

ב־Netlify בחרו **Add new project → Import an existing project → GitHub**, אשרו גישה לריפוזיטורי `Danielkoren12/noizer`, בחרו את הענף **main** ולחצו **Deploy**. ההגדרות נקראות מהקובץ בפרויקט, ולכן אין צורך להקליד פקודות או הגדרות בנייה. לאחר חיבור הענף, שינויים שיידחפו ל־main יפעילו פרסום חדש אוטומטי.

סקריפט ההכנה המקומי `scripts/build_site.py` מעתיק רק HTML, CSS, JavaScript, robots.txt, נכסים ציבוריים ורישיונות פונטים. סקילים, בדיקות, הוראות עבודה וקובץ התצוגה העצמאית אינם מתפרסמים. תיקיית public נשמרת ב־Git; כלי הפיתוח מעדכן אותה יחד עם המקורות לפני העלאת שינויים. אין צורך להריץ סקריפט ב־Netlify או לבצע פעולה ידנית בכל עדכון.

אפשר לפרסם את קבצי האתר על כל אירוח סטטי באמצעות העלאת התיקייה, ללא שלב בנייה. יש לפרסם רק את `index.html`, `styles.css`, `app.js`, `robots.txt` ואת `assets/`; סקילים, בדיקות ומסמכי עבודה אינם חלק מהאתר הציבורי.

העמוד כולל כותרת, תיאור, כותרות מסודרות, עובדות עסק גלויות ונתוני Organization ו־Service מובנים. התוכן זמין גם ללא JavaScript, ו־`robots.txt` מאפשר סריקה.

הדומיין הרשמי הוא `https://noizer.co.il/`. נוספו canonical, כתובת `og:url`, נתונים מובנים ומפת אתר ב־`sitemap.xml`; `robots.txt` מפנה אליה. הפניות מהכתובת הישנה ומ־www מוגדרות ב־`_redirects`. תגיות `og:image` ו־`twitter:image` מפנות לתמונת שיתוף ייעודית של סימן NOIZER הקיים באתר: `assets/noizer-share.png`, במידות 1200×630. ליצירה מחדש משתמשים בסקריפט המקומי `scripts/build_share_image.py`, שמצלם את סימן הטקסט הקיים עם הפונט המקומי, ללא יצירת AI או הורדת נכסים. לאחר מכן מרעננים את `public/` ואת `preview.html` בסקריפטים הקיימים. שירותי שיתוף עשויים לשמור תצוגות קודמות במטמון, והודעה שכבר נשלחה לא בהכרח תתעדכן. יש לאמת באירוח שאין חסימת סריקה באמצעות HTTP headers או אימות משתמש. הכללת האתר בחיפוש או במנוע AI אינה מובטחת רק בזכות ההכנה הזו.

הוראות קצרות לחיבור Google Search Console, הגשת מפת האתר וסדר עדיפות לשיפור הגילוי נמצאות ב־[SEO-NOTES.md](SEO-NOTES.md). חיבור חשבון, אימות בעלות ובקשת אינדוקס טרם בוצעו.

## גרסת הבסיס

גרסת הבסיס המאושרת הנוכחית היא `v1.2.0-baseline`. היא כוללת את הילד הקטן המוצג מהגב, כתיבה מסונכרנת והליכה בין השורות, צליל ספריי המוגדר להפעלה אוטומטית ללא כפתור סאונד, מעברים משוננים וקישור WhatsApp. התג מצביע על קבצי האתר, התצוגה העצמאית, הבדיקות וסקילי העיצוב. כשמבקשים ״חזרה לגרסת הבסיס״, יש להשתמש בתג הזה.

הגרסאות הקודמות נשמרו בהיסטוריה לגיבוי. לפני סבב שינויים יש לשמור נקודת חזרה נוספת. אפשר לבקש מכלי הפיתוח לחזור לגרסת הבסיס או לשחזר רק רכיב מסוים, בלי להקליד פקודות.

שמירה ב־GitHub היא גיבוי הקוד וההיסטוריה. היא אינה פרסום האתר באינטרנט.

האנימציה שקטה לחלוטין. קוד הפקת הצליל וכפתור ההפעלה החוזרת הוסרו. דילוג, הפעלה פעם אחת בכל ביקור והתאמה להעדפת פחות תנועה נשמרו.
