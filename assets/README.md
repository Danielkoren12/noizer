# נכסים

נכסי הדוגמאות נמסרו בידי המשתמש. שני הסרטונים ותמונות פתיחה שחולצו מהם נמצאים ב־`examples/`. אין תמונות חדשות שנוצרו ב־AI. אין נכס לוגו מקורי זמין כקובץ בפרויקט. שני קובצי הבאנרים המקוריים שהמשתמש מסר ב־Archive.zip נמצאים גם הם ב־`examples/`, ללא שינוי.

`favicon.svg` הוא סימן N פשוט שנכתב כקוד; הוא אינו הלוגו המקורי.

## פונטים

הפונטים הועתקו ממאגר Google Fonts הרשמי: https://github.com/google/fonts

- Karantina Bold, Rony Koch / Karantina Project Authors — SIL Open Font License 1.1. המקור: `ofl/karantina/Karantina-Bold.ttf`.
- Rubik variable, Rubik Project Authors — SIL Open Font License 1.1. המקור: `ofl/rubik/Rubik[wght].ttf`.
- Permanent Marker, Font Diner — Apache License 2.0. המקור: `apache/permanentmarker/PermanentMarker-Regular.ttf`.

הרישיונות נשמרו במלואם לצד הפונטים תחת `fonts/`. יש לשמור אותם בעת הפצה.
